# Decision Tree

The following diagram illustrates the lifecycle of a customer message and how it flows through the various AI and system components.

```
Customer sends message
        ↓
Conversation Engine
        ↓
Extract Facts
        ↓
Location Resolver
        ↓
Eligibility
        ↓
Confidence
        ↓
Readiness
        ↓
Recommendation
        ↓
Project Workspace
```
