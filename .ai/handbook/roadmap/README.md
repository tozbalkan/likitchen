# Roadmap

Ideas are never rejected; they simply wait in the queue. When a new suggestion arrives, it is added to the roadmap — if it does not pass the V1 Freeze test defined in `rules/PRODUCT_RULES.md`, it is placed in the backlog.

- [MVP (V1)](./MVP.md)
- [V2 Features](./V2.md)
- [Backlog (V3+)](./BACKLOG.md)

## How to add items to the Roadmap

1. The idea emerges (not while writing code — see Rule #1).
2. The V1 Freeze test is applied.
3. If it fails the test, it is added to the V2 or Backlog (V3) depending on when it makes sense.
4. Rule #3 is applied: if there is no recurring signal, the item waits in the table; it is not automatically moved up.
