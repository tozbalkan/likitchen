# Project Documentation Hub (.ai)

Welcome to the engineering handbook for LI Kitchen & Bed. This repository follows Documentation First Development.

**Golden Rule:** No new handbook documents unless implementation reveals a real gap.

## Directory Structure

- **[handbook/](handbook/)**: What we are building. The single source of truth for architecture, rules, and contracts.
- **[agents/](agents/)**: How we work. The Operating Contract and agent specifications defining strict responsibilities.
- **[capabilities/](capabilities/)**: What we are currently building. Machine-readable capability manifests for orchestration.
- **[CAPABILITIES.md](CAPABILITIES.md)**: The human-readable map of all capabilities.
