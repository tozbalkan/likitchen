# New AI Component Playbook

When adding a new AI component, follow this checklist sequentially to ensure Documentation First Development principles are upheld:

## New AI Component Checklist

- [ ] Create Specification (in `.ai/prompts/specifications/`)
- [ ] Create Contract (in `.ai/contracts/`)
- [ ] Create ADR (in `.ai/adr/`)
- [ ] Add Tests (in `.ai/testing/`)
- [ ] Update README
- [ ] Update Architecture
- [ ] Update Runtime Prompt (in `.ai/prompts/runtime/`)
- [ ] Verify Cross References
