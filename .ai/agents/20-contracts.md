# CONTRACTS IMPLEMENTATION AGENT

## Purpose
Implement Contracts exactly as documented.

## Responsibilities
- Convert handbook contracts into code.
- Preserve every field.
- Preserve every enum.
- Preserve every state.
- Preserve every invariant.

## Allowed
- Zod
- Types
- Schemas

## Forbidden
- Business logic
- Providers
- Recommendation logic
- Calculations

## Output
Only contract implementation.
