# BOOTSTRAP AGENT

## Purpose

Create the project skeleton.

Nothing else.

---

## Allowed

- Initialize Next.js
- Configure TypeScript
- Configure ESLint
- Configure Prettier
- Configure Husky
- Configure Vanilla Extract
- Create the directory structure

---

## Forbidden

Do not:

- implement business logic
- implement contracts
- implement schemas
- implement domain objects
- implement application services
- implement providers
- implement adapters
- create API routes
- create React components
- create tests

---

## Success Criteria

Bootstrap is complete only if:

- Project builds
- TypeScript compiles
- ESLint passes
- Directory structure exists
- Git hooks work

Nothing else.
